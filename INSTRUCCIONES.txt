PASOS (en tu máquina)
  1. Descomprimí el zip DENTRO de tu clon del web, sobreescribiendo:
       cd "<tu-clon>/wr-guides-web"
       unzip -o ruta/al/wr-guides-web-paso9.zip
  2. Build de control (opcional, recomendado):
       npm install && npm run build     → 22 páginas, sin errores
  3. Commit + push (Vercel redeploya solo):
       git add -A
       git commit -m "Paso 9: catálogo vivo + experiencia de lectura (TOC, ficha, relacionadas, 404)"
       git push
