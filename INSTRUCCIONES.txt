WR-GUIDES-WEB · V2 PRODUCTO — FAVORITOS + SEGUIR LEYENDO  (2026-10-08)
══════════════════════════════════════════════════════════════════

REQUISITO: la API v0.5.0 desplegada Y la migration 002 aplicada en Supabase
(sin eso, el botón ★ no aparece: degradación silenciosa, el resto intacto).

QUÉ INCLUYE
  · lib/api.ts               cliente: favorito(), setFavorito(), misFavoritos()
  · lib/recientes.ts         historial LOCAL (localStorage "wrg_recent", máx 8)
  · components/FavButton.tsx  ☆ Guardar / ★ En favoritos · N (toggle optimista
                             con resincronización si el POST falla + evento
                             guide_favorite en Vercel Analytics)
  · components/RecentTracker.tsx  registra la visita en el historial local
  · components/HomePersonal.tsx   home: "★ Tus favoritas" (API) +
                             "📖 Seguir leyendo" (local); sin datos → no pinta
  · components/Catalogo.tsx  ★ en las cards que ya tenés favoritas
  · app/page.tsx, app/guias/[slug]/page.tsx, styles/globals.css (ambos temas)
  · README.md

PASOS
  1. cd "<tu-clon>/wr-guides-web" && unzip -o ruta/al/wr-guides-web-v2.zip
  2. (Opcional) npm run build → 22 páginas
  3. git add -A && git commit -m "V2: favoritos anónimos + seguir leyendo + estrellas en catálogo" && git push

VERIFICACIÓN EN PRODUCCIÓN
  a. /guias/jinx → "☆ Guardar · N" junto a los badges; click → ★ amarillo;
     F5 persiste; otro navegador/incógnito → contador igual, estrella apagada
     (el favorito es por visitante).
  b. Home con favorito existente → sección "★ Tus favoritas".
  c. Visitá 2-3 guías y volvé al home → "📖 Seguir leyendo" (solo tu navegador).
  d. Catálogo: ★ al lado del título de tus favoritas.
  e. Tema clásico: botón y estrellas con paleta dorada suave; Jinx: glow amarillo.
  f. Vercel Analytics → evento guide_favorite apareciendo con los toggles.

NOTAS
  · El historial "seguir leyendo" es 100 % local: no viaja a ningún servidor
    (ni a la API): borrar datos del navegador lo resetea.
  · Los favoritos viven en Supabase (tabla guide_favorites) atados al
    visitor-id: mismo navegador = mismo favorito; cambiar de dispositivo no
    los lleva (eso sería V2-cuentas, fuera de alcance por diseño).
