PASOS
  1. cd "<tu-clon>/wr-guides-web" && unzip -o ruta/al/wr-guides-web-seo.zip
  2. (Opcional) npm run build  → 22 páginas + sitemap.xml/robots.txt en output
  3. git add -A && git commit -m "SEO: sitemap, robots y OpenGraph/Twitter con card de marca" && git push

VERIFICACIÓN EN PRODUCCIÓN
  a. https://wr-guides-web.vercel.app/sitemap.xml → 19 URLs (home + meta + 17 guías)
  b. https://wr-guides-web.vercel.app/robots.txt → allow + sitemap
  c. Ver una guía → ver código fuente: meta og:title/og:description/og:image +
     twitter:card por guía.
  d. Prueba real de share: pegá https://wr-guides-web.vercel.app/guias/jinx en
     un chat de WhatsApp o en el Slack/Discord que uses → la card aparece con
     la imagen neón y el título de la guía (los crawlers de cada plataforma
     pueden tardar minutos en cachear la primera vez).

NOTAS
  · La card es única de marca (no por guía): título y descripción sí son por
    guía, que es lo que lee la gente en el share. Cards dinámicas por campeón
    (con su nombre en la imagen) quedan como pulido futuro vía opengraph-image.tsx.
  · metadataBase apunta al dominio vercel.app: si algún día hay dominio
    propio, cambiar ahí + en sitemap.ts/robots.ts (3 líneas).
